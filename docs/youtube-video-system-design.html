핵심 기능 상세

🎯 Soul ID (캐릭터 일관성)
참조 이미지로 캐릭터 정의 → 모든 장면에서 동일 인물/캐릭터 유지. 채널 아바타, 시리즈 캐릭터에 필수.
🎬 Cinema Studio
AI Director가 스크립트를 장면별로 분할, 가상 카메라(렌즈/초점거리) 설정까지 자동화.
🔗 URL-to-Video
제품 URL 입력 → 자동으로 광고 영상 생성. 제품 리뷰, 언박싱 콘텐츠에 활용.
🎨 Edit Image/Video
브러시 기반 인페인팅으로 특정 영역만 수정. 로고 제거, 배경 교체 등.
🔊 Voice Clone
나레이션용 AI 음성 생성. 일관된 채널 보이스 유지.
📐 Topaz Upscale
AI 영상을 4K로 업스케일링. 유튜브 고화질 업로드용.

구현 예시 (의사 코드)

# 유튜브 영상 제작 파이프라인 async def create_youtube_video(topic, style): # 1. 스크립트 생성 (Claude) script = await claude.generate_script(topic) # 2. 스토리보드 분할 (Cinema Studio) shots = await higgsfield.cinema_studio( script=script, camera="Sony A7S III", lens="35mm" ) # 3. 캐릭터 정의 (Soul ID) character = await higgsfield.create_soul_id( reference_image="avatar.png" ) # 4. 장면별 영상 생성 clips = [] for shot in shots: clip = await higgsfield.generate_video( prompt=shot.prompt, model="veo-3.1", soul_id=character, duration="5s" ) clips.append(clip) # 5. 오디오 생성 voiceover = await higgsfield.generate_audio(script) bgm = await higgsfield.generate_audio(style="cinematic") # 6. 영상 합성 final = await ffmpeg.concat(clips) final = await ffmpeg.add_audio(final, voiceover, bgm) # 7. 후처리 final = await higgsfield.upscale_video(final, scale="4K") # 8. 썸네일 생성 thumbnail = await higgsfield.generate_image( prompt=f"YouTube thumbnail: {topic}" ) return final, thumbnail

MCP API 통합 가이드

실제 Higgsfield MCP 도구를 활용한 구현 방법

영상 생성 도구

# 단일 영상 생성 generate_video({ model: "seedance_2_5", // 기본, 빠른 생성 prompt: "제품 홍보 영상...", aspect_ratio: "16:9", // 유튜브 가로 duration: 5 }) # 배치 생성 (1-12개 병렬) generate_video_batch({ requests: [ { index: 0, params: { model: "kling3_0", prompt: "장면1" } }, { index: 1, params: { model: "kling3_0", prompt: "장면2" } } ] }) # 모션 전이 (캐릭터에 동작 적용) motion_control({ image_id: "캐릭터_이미지_uuid", motion_video_id: "참조_동작_uuid", resolution: "1080p" })

이미지 생성 도구

# 일반 이미지 (썸네일 등) generate_image({ model: "gpt_image_2_5", // 기본, 포토리얼 prompt: "YouTube 썸네일: 긴장감 있는...", aspect_ratio: "16:9" }) # 캐릭터 생성 (Soul ID) generate_image({ model: "soul_2", prompt: "채널 마스코트 캐릭터", medias: [{ value: "soul_id_uuid", role: "soul_id" }] }) # 제품/광고용 generate_image({ model: "marketing_studio_image", prompt: "제품 광고 이미지" })

오디오 생성 도구

# TTS 나레이션 generate_audio({ model: "seed_audio", // ByteDance 기본 prompt: "안녕하세요, 오늘은...", voice_type: "preset", voice_id: "korean_male_1" }) # 음성 복제 (나만의 보이스) create_voice_from_confirmed_audio({ audio_media_id: "내_음성_샘플_uuid", name: "채널보이스" }) # 다국어 더빙 (립싱크) dubbing({ video_id: "원본_영상_uuid", target_language: "eng" // 영어로 더빙 })

후처리 도구

# 영상 업스케일링 (4K) upscale_video({ provider: "topaz", video_id: "영상_uuid", resolution: "2160p" // 4K }) # 이미지 업스케일링 upscale_image({ image_id: "썸네일_uuid", width: 1280, height: 720, resolution: "4k" }) # 이미지 확장 (아웃페인팅) outpaint_image({ image_id: "원본_uuid", aspect_ratio: "16:9" // 정사각형→가로로 확장 })

쇼츠/리스타일 도구

# 쇼츠 스튜디오 (영상 리스타일) shorts_studio_create({ source_video_id: "원본_영상_uuid", preset_id: "스타일_프리셋_uuid", preset_source: "cms", aspect_ratio: "9:16" // 세로 쇼츠 }) # 유튜브 영상 분석 video_analysis_create({ youtube_url: "https://youtube.com/watch?v=..." })

워크플로우 & 미디어

# 워크플로우 가이드 로드 get_workflow_instructions({ workflow: "ad-multiplier" // 광고 변형 워크플로우 }) # 마케팅 스튜디오 (템플릿 갤러리) show_marketing_studio_v2({ category: "ugc" // UGC 광고 템플릿 }) # URL에서 미디어 가져오기 media_import_url({ url: "https://example.com/image.jpg", type: "image" })
